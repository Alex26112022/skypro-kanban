# Skypro Kanban

Канбан-доска для ведения задач.

## Стек

React 18 · Vite · JavaScript · CSS · ESLint

## Реализовано

- Вёрстка разбита на 8+ компонентов, стили в `App.css`
- Модалка `PopUser` на `useState`
- Данные карточек в `src/data.js`, рендер через `filter` + `map` + `key`
- Имитация загрузки: `useState` + `useEffect` + `setTimeout`, лоадер по центру

## Запуск

```
npm install && npm run dev
```
